0. KONTEKS GAME DAN ARAH ASET
======================================================================

KREML 1991 adalah political survival / alternate-history game berbasis teks,
berlatar pemerintahan Uni Soviet 1964–1991 dengan jalur alternatif sampai
2001. Nuansa yang paling cocok: kantor Sekretaris Jenderal, Politbiro,
Gosplan, dokumen rahasia, arsip negara, telepon meja, foto tokoh, gedung
pemerintahan, poster era Soviet, kota-kota Soviet, dan rekaman sejarah.

Catatan desain: halaman game menyebutkan bahwa antarmuka utamanya adalah
board/docket, directive, dan crisis (bukan peta). Jadi foto bisa paling
berguna untuk event dossiers, halaman landing, layar briefing, profil tokoh,
atau ilustrasi arsip — tidak harus memenuhi seluruh layar permainan.

======================================================================

Untuk SETIAP aset yang benar-benar dimasukkan ke game, catat:

Asset title:
Creator / photographer:
Source page URL:
Direct download URL (optional):
License name and version:
License URL:
Changes made (cropped / recolored / edited / none):
Where used in KREML 1991:
Date downloaded:

Contoh format kredit di game / credits.txt:
"Leonid Brezhnev Portrait (1)" — Ulrich Kohls / Bundesarchiv,
source: [URL], licensed under CC BY-SA 3.0 Germany [license URL].

Jangan hanya menulis “Source: Wikimedia Commons”. Catat pencipta dan lisensi
file spesifik. Simpan salinan halaman sumber/lisensi saat aset diunduh karena
metadata atau status file bisa berubah.

11. CATATAN LISENSI PENTING
======================================================================

1. Tautan kategori (Commons categories) adalah tempat mencari kandidat, BUKAN
   izin penggunaan untuk semua file di kategori itu.
2. Selalu buka halaman file individual, cek bagian Licensing / Rights Advisory,
   nama pencipta, sumber asli, tanggal, dan ketentuan atribusi.
3. Public domain, CC0, CC BY, dan CC BY-SA memiliki arti berbeda. CC BY wajib
   diberi kredit; CC BY-SA memiliki ketentuan ShareAlike; CC0 paling sederhana.
4. Foto tokoh terkenal tidak otomatis bebas hak cipta. Hak foto dipegang oleh
   fotografer, agensi, atau arsip, bukan oleh tokoh yang difoto.
5. Untuk musik, komposisi dan rekaman suara adalah dua lapis hak yang berbeda.
   Gunakan halaman lisensi untuk rekaman spesifik, bukan hanya status lagu.
6. “No known restrictions” dari arsip bukan selalu sama dengan public domain.
   Pastikan kecocokannya dengan distribusi internasional game.
7. Hindari memakai gambar/audio dari hasil Google Images, blog, Pinterest,
   media berita, atau akun sosial tanpa menemukan sumber dan lisensi aslinya.
8. File sumber ini adalah shortlist riset, bukan nasihat hukum. Untuk aset yang
   menjadi bagian utama game komersial, simpan bukti lisensi dan minta review
   hukum bila ada keraguan.
