SOVIET-ERA GAME REFERENCE IMAGE SOURCES
========================================
Purpose: image-source links for an AI agent building a historically inspired game.
Main period: USSR, 1960-1991.
Follow-up period: post-Soviet transition, 1992-2000.

IMPORTANT
- These are source/category pages, not guaranteed direct image-file URLs.
- Open each individual file page and check its date, location, author, and license before downloading or using it.
- Wikimedia Commons files have different licenses; do not assume every image is public domain or free for every use.
- Prefer files with clear reuse terms (for example, CC0, public domain, or an appropriate Creative Commons license) and keep attribution/license metadata.
- Check that the photograph depicts the historical period, not a modern reconstruction, museum display, reenactment, or present-day view.
- A category can contain unrelated or later photographs; verify every candidate image.
